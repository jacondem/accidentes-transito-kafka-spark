# Datos

Descargue `Road Accident Data.csv` desde la fuente original del dataset
y guárdelo aquí como `Road_Accident_Data.csv`. Este archivo no se versiona.

Registros de accidentes de tráfico en Kensington y Chelsea (enero de 2021)
Este conjunto de datos proporciona registros detallados de accidentes de tráfico ocurridos durante enero de 2021. Incluye información como la fecha del accidente, el día de la semana, el control de la intersección, la gravedad del accidente, las coordenadas geográficas, las condiciones de iluminación y meteorológicas, los detalles del vehículo y más.

https://www.kaggle.com/datasets/nextmillionaire/car-accident-dataset
